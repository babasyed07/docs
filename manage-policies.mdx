---
title: "Manage Policies"
---
The Manage Policies page is the central hub in Reva for overseeing application contexts and their governance setup. From this page, you can create and organize application contexts, connect them to policy stores, and manage environments such as development, staging, and production.  

It provides a single view of all governance-related elements, making it easier to:  
1. Search across applications and policies using free text.
   Enter keywords to quickly locate applications or policy contexts.
2. Filter by Category or Application
   Use the dropdown menus to narrow the results.  
   - **Categories:** Default, Retail, Healthcare, Finance, AI Workload
   - **Applications:** Select specific apps to display only their contexts
3. Sort Options   
   Organize the view by selecting from available choices:
   - **Name A to Z** - Displays applications in alphabetical order starting with A.
   - **Name Z to A** - Displays applications in reverse alphabetical order starting with Z.
   - **Last Updated (closest to now)** - Shows applications with the most recent updates first.
   - **Status Pending first** - Lists applications with pending status at the top.
   - **Status Completed first** - Lists applications with completed status at the top.
4. Review application cards with details like category (e.g., Finance, Retail), Description (summary of the application context), status (e.g., Pending, Completed), and Metrics (Violations, Warnings, Errors)
4. Take quick actions through the three vertical dots (⋮) menu to Application **Setttings** or **Delete**.
5. Ensure that every application context is linked to the right policies and remains compliant with organizational standards.

By consolidating these capabilities, the Manage Policies page enables teams to maintain visibility, enforce consistent authorization across environments, and simplify day-to-day governance tasks.
