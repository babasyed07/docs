For traffic you can't (or don't want to) instrument with the Python SDK, Reva is building enforcement at your **API gateway** and **service mesh**, plus a **Java SDK** for JVM services — no application changes or custom HTTP steps required. Every request is still evaluated by the [Reva Trust Guardian](/ai-workload-security-overview).

Planned coverage:

- **Kong plugin** — enforce Reva authorization at the **Kong API gateway**.
- **Istio plugin** — enforce Reva authorization in the **Istio service mesh**.
- **Java SDK** — the same decorator + proxy model as the Python SDK, for JVM services.
