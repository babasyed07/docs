Reva brings everything together in a few core areas. Use this map to find where to go for each task — the same sections serve every use case (custom application authorization, AI workload security, and token enrichment).

## Platform Sections

<CardGroup cols={2}>
  <Card title="Home / Insights" icon="house" href="/landing-page">
    Real-time insights and key performance indicators across all your applications.
  </Card>
  <Card title="Manage Policies" icon="layer-group" href="/manage-policies">
    Organize applications and their environments, policy stores, schemas, and access control policies in one place — for agentic, custom application, or infrastructure policies.
  </Card>
  <Card title="Integrations" icon="plug" href="/integration-overview">
    Connect the policy stores, identity providers, CMDBs, agent registries, API gateways, and shared-signal sources that authorization decisions depend on — bringing signals in and pushing enforcement out.
  </Card>
  <Card title="Library" icon="book" href="/library">
    Central place to store, share, and reuse policies, schemas, and entity definitions.
  </Card>
  <Card title="Guardrails" icon="shield-halved" href="/guardrails/overview">
    Configure design guardrails for policies and posture, and runtime guardrails for content, context, behavior, and intent on every request.
  </Card>
  <Card title="Access Explorer" icon="compass" href="/use-access-map">
    Discover the capabilities of your access controls with the Reva AI Access Explorer.
  </Card>
  <Card title="Decision Logs" icon="list-check" href="/ai-workload-decision-logs">
    Search, filter, and investigate authorization decisions, with the policies and guardrails behind every verdict.
  </Card>
</CardGroup>

<Note>
  **Decision Logs** are available globally across the platform, and each policy store also keeps its own store-specific decision logs.
</Note>
