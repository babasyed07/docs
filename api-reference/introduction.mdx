title: 'Reva API Documentation Overview'
---
The Reva API provides a complete set of services for authorization decisions, access discovery, and the data that powers them. The APIs are organized into the following families.

## Authorization APIs
Real-time access evaluation and authorization decisions.

- **Agentic AI Evaluation** (`POST /pdp/access/v1/ai/evaluation`) — authorize each call in an agent chain (user → agent, agent → agent, agent → tool, MCP server, or model). See [Agent Authorization Evaluation API](/ai-workload-developer-evaluation-api).
- **AuthZEN Evaluation** (`POST /pdp/access/v1/evaluation`) — AuthZEN-compatible access evaluation based on subject, action, resource, and context.
- **PDP Edge Authorize** (`POST /v1/authorize`) — single or batch authorization decisions at the edge.

## Access Search APIs
Discover access relationships — search the subjects, actions, or resources permitted for a given query (`/access/v1/search/*`).

## Data Fabric APIs
Bring data in and keep authorization performant.

- **Entity Ingestion** (`/ingestion/v1/entity*`) — create, update, replace, and delete entities, with bulk support. Entity models align with your policy schemas.
- **Access Map** (`PUT /v1/application/{applicationName}/policy-store/{policyStoreName}/accessmap`) — refresh the resolved permissions and relationships used for fast policy evaluation.

<Info>**Security:** All APIs are secured with Bearer Token authentication (`Authorization: Bearer <token>`). For the Agentic AI Evaluation API, use your **PDP Auth Token** from the Developer Settings page.</Info>
