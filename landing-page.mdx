Your starting point for policy governance and authorization 

The Reva Home Page is designed as a welcoming, intuitive dashboard that helps you quickly navigate your authorization journey. With its clean layout and curated resources, you'll find everything needed to start securing applications efficiently. 

## Page Layout Overview 

<img height="200" src="images/landing-page.png" />

1. **Top Banner:** Personalized welcome message  
2. **Get Started with Reva Section:** Foundational setup actions  
3. **Explore Section:** Self-paced learning resources 

## Key Sections Explained 

1. Welcome Message  
   - Encourages quick setup  
   - Reassures about available support  

<Info>Welcome! 🚀 Let’s get started with a quick setup. Your journey with Reva begins here. Reach out anytime—we’re here to make this experience seamless for you.</Info> 

2. Get Started with Reva  
   Quick-access widgets for initial setup  

   | **Widget**                     | **Purpose**                 | **Action**                        |
   |:------------------------------|:----------------------------|:----------------------------------|
   | **Discover AVP Policy Stores**| Connect AWS accounts        | Start managing AVP policies       |
   | **Onboard your Applications** | Begin authorization setup   | Launch application onboarding     |  

3. Explore Resources  
Self-learning tools for all skill levels   

   | **Resource**              | **Format** | **Best For**                                |
   |:--------------------------|:-----------|:---------------------------------------------|
   | **Discover AVP Policy**       | Document       | New users understanding policy management    |
   | **Policy Designer Guide** | Document   | Creating custom access controls              |
   | **Approval Workflows** | Document     | Configuring governance processes             |  

4. View More Resources   
Expanded knowledge base access 
   - Single "View More" link to: 
   -  Tutorial library 
   -  API documentation 
   -  Use case playbooks 
   -  Compliance templates 

## Why This Design Works 

1. User-Centric Flow: Guides from setup → learning → advanced tools   
2. Progressive Disclosure: Presents core actions first, advanced options later   
3. Visual Hierarchy: Important actions stand out with clear CTAs   
4. Contextual Help: Resources match user journey stage
