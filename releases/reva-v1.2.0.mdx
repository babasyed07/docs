# V1.2.0 July 29, 2025  
## What's New  
### Guardrail Insights  
The **Guardrail Insights** view provides a clear summary of **warnings** and **violations** detected in policies across applications.

- Displays a **severity breakdown chart** for quick visual analysis  
- Lists each warning or violation with **Guardrail Name**, **Application Name**, and **Severity**  
- Helps identify overly permissive policies, conflicting rules, or Governance gaps before activation.  
### Environment Data for Policy Simulation  
Reva now supports injecting environment-specific data into Policy Stores via the Data Ingestion APIs ([View Ingestion API Docs](https://docs.reva.ai/api-reference/data-ingestion-apis/create-entities)), enabling context-rich simulations and pre-deployment testing of policies.  
- Simulate access policies using real-world deployment conditions  
- Strengthens accuracy of access control policies before enforcement
