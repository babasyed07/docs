---
title: "Select a coding agent"
---

The row of tabs: Claude Code, Kiro, Codex CLI, Cursor, GitHub Copilot, switches which agent you are configuring. Plan, members, and plugin setup are all held per agent, so a change on one tab does not carry to another.

Configure one agent completely before moving to the next. If a tab shows a request screen instead of configuration, that agent is not yet enabled for your workspace. see [Request an agent](/ai-coding-agents/workspace-settings/plan-and-users/request-an-agent).
