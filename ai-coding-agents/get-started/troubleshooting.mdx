---
title: "Troubleshooting"
---

| What you are seeing | What to do |
|:--------------------|:-----------|
| A workspace already exists for your organization | Each organization has exactly one workspace, and someone at your organization has already created it. Contact your existing workspace administrator to be added. If you need a separate environment for evaluation, contact the Reva team. |
| Provisioning is taking longer than expected | Provisioning may take up to fifteen minutes. No action is needed. You will receive an email when the workspace is ready, and it is safe to close the browser in the meantime. |
| You are asked to add at least one team member | A coding agent cannot be set up with nobody assigned to it. Add at least one member, You can invite others. |
| Insights is empty after setup | Expected until a developer/user installs the plugin and runs a session. Confirm the plugin is installed on at least one machine and that a prompt has been run since installation. |
| The plugin cannot connect to the workspace | Check that the OAuth token were entered exactly as shown, with no trailing spaces. If the token has been regenerated since installation, the old one no longer works — reissue the current token from Settings → Plugin . |
| A developer/user cannot reach the plugin repository | Confirm the developer/user has been added to the workspace and is signed in to their own coding-agent account. If access is still refused, contact the Reva team. |
| A coding agent your team uses is not listed | Request it during workspace creation, or contact the Reva team. Availability is confirmed case by case and does not block you from governing the agents already available. |
