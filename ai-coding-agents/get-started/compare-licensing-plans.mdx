title: "Compare licensing plans"
---

A plan is selected per coding agent, so you can run different plans for different agents if that suits your organization.

|  | Individual | Teams | Enterprise |
|:-|:-----------|:------|:-----------|
| **Team member onboarding** | Developers are invited by email and join individually. | You add developers directly; no invitation is required. | N/A |
| **Plugin configuration** | Each developer configures the plugin themselves, using the instructions they receive. | You configure the plugin once, centrally, for the whole team. | N/A |
| **Licence management** | Each developer holds their own licence. | Your team draws from a shared licence pool that you manage. | Contact the Reva team for Enterprise Workspace |
| **Best suited to** | Smaller teams, and teams that prefer to manage licensing independently. | Teams that want centralised administration and a single shared pool. | Large organizations with advanced governance, compliance, or deployment requirements. |
| **How to start** | Available directly in the workspace. | Available directly in the workspace. | Contact the Reva team and we will set it up with you. |
