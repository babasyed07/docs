title: "Common tasks"
---

After onboarding, here is where to go for the things administrators do most.

| I want to… | Where to go |
|:-----------|:------------|
| Add another coding agent | Settings. If the agent is not listed, request it from the Reva team. |
| Invite more developers to an agent | The members section in your workspace. |
| Check who has installed the plugin | Your workspace install status for that agent. |
| Reissue or rotate the OAuth token | Settings → Plugin . |
| Review or change the default policies | Policies in your workspace. |
| See what agents attempted and what was stopped | Insights. |
| Pull the decision record for an audit | Decision logs. |
| Change your licensing plan | Contact the Reva team. |
