**Reva is an AI-powered policy governance and authorization platform.** It gives developers and business stakeholders one place to manage **who — and which agent — can access what**, with precision and confidence.

Reva began with fine-grained authorization for custom applications and now spans multiple authorization use cases on the same Cedar policy engine — securing **agentic AI workloads**, **enriching identity tokens**, and more to come. Pick the one that matches your goal in **[Choose Your Use Case](/choose-your-use-case)**.

## Core Authorization Components

Every use case is built on the same standard authorization architecture:

| **Component** | **Role**              | **Function**                                          |
|:--------------|:----------------------|:------------------------------------------------------|
| **PAP** (Policy Administration Point) | **Policy Designer**      | Create, manage, and govern access policies             |
| **PIP** (Policy Information Point)      | **Data Hub**             | Integrate user/resource data for decision-making       |
| **PDP** (Policy Decision Point)         | **Decision Engine**      | Evaluate access requests using Cedar policies          |
| **PEP** (Policy Enforcement Point)      | **Enforcement Layer**    | Apply decisions within your applications and agents    |

## What is Reva?

Reva is an AI-powered platform that combines three essential authorization components:

1. **Policy Designer (PAP)**  
   Create, manage, and govern access policies.
2. **Data Hub (PIP)**  
   Integrate user, resource, and agent data for authorization decisions.
3. **Decision Engine (PDP)**  
   Evaluate access requests using the Cedar policy language.

<Info>
  Reva works seamlessly with Amazon Verified Permissions (AVP) and includes its own Cedar-based decision engine — plus the **Reva Trust Gateway (RTG)** for runtime authorization of AI agents and token enrichment.
</Info>

## AI-Assisted Authoring

Across every use case, Reva uses AI to make authorization easier to build and govern:

- **AI-Driven Policy Creation:** Generate policies from plain-English descriptions.
- **AI-Based Schema Generation:** Generate and maintain schemas from your application or agent data model.
- **Access Search:** Search and analyze access data across systems to surface risky or unauthorized access patterns.

<Note>
  Don't confuse **AI-assisted authoring** (AI that helps you *write* policies) with **AI Workload Security** (Reva *authorizing* your AI agents at runtime). Both are covered in this guide.
</Note>

## Built for Everyone

Whether you're a developer, security architect, or business user, Reva helps you:

1. Design policies with no-code tools or an AI-assisted editor.
2. Model RBAC, ABAC, and ReBAC access controls.
3. Generate policies from plain-English descriptions.
4. Test authorization scenarios before deployment.
5. Visualize access rules with the Access Graph.

## How Reva Enhances Your Ecosystem

Reva supercharges authorization across applications and AI workloads by providing:

1. **Central policy management (PAP)** — manage policies in one place for consistent governance.
2. **Simplified data integration (PIP)** — combine data from multiple sources for real-time decisions.
3. **Flexible decision engine (PDP)** — evaluate access locally, via AVP, or through the Reva Trust Gateway.
4. **Access Graph visualization** — see who (or which agent) has access to what, and why.
5. **AI-driven policy and schema generation** — accelerate authoring and maintenance.
6. **AI-enhanced access search** — identify unauthorized access patterns and risks.
7. **Library** — a centralized repository of reusable policies, schemas, and entity definitions.
8. **Guardrails** — a policy-governance framework that standardizes policies and detects violations.
