**The Intent & Behavior-Based Access Control (IBAC) platform.** Reva is a unified authorization control plane that decides — in real time — whether an action by a human or an AI agent is allowed. It goes beyond *who* an identity is to evaluate *what they're trying to do* and *whether it's appropriate*, keeping autonomous agents visible, governable, and accountable.

*Inspect the intent. Authorize the action.*

## Why Reva

Identity tells you *who* an agent is. It can't tell you whether the agent's *action* is appropriate — and autonomous agents act at machine speed, across many hops, often on behalf of someone else. Static, identity-only controls leave three gaps:

| Risk | What it looks like |
|:-----|:-------------------|
| **Excessive Agency** | Over-permissioned agents take destructive actions far beyond what anyone intended. |
| **Intent Decay** | Context changes at every hop, so point-in-time permission checks stop reflecting what's actually happening. |
| **Confused Deputy** | Agents delegate access across systems, creating unbounded chains with no clear accountability. |

## The IBAC Shift

Reva closes those gaps with **Intent & Behavior-Based Access Control** — authorization that evaluates the *action*, not just the actor. It shifts the question from *"what access does this agent have?"* to *"is this action appropriate, right now?"*

- **Intent-aware** — Reva parses the explicit intent of a request into fine-grained permissions and checks it against business context in real time.
- **Runtime & adaptive** — decisions happen continuously, at every tool call, API request, and MCP boundary — not once at sign-in.
- **Zero Standing Privileges** — access is granted just-in-time for the narrow intent of an authorized task, then revoked, neutralizing authorization drift.
- **Deterministic** — because enforcement is policy-driven, Reva can block an inappropriate action even if the agent's reasoning or LLM is compromised by prompt injection.

## Built for Every Agent and App

Reva governs access for everything in a modern environment:

- **AI agents** — enterprise agents (Microsoft Copilot, Claude Cowork), coding agents (Claude Code, Cursor, Kiro), and autonomous pro-code agents (LangChain, n8n, and more).
- **Applications and APIs** — custom apps, microservices, SaaS, data platforms, and Kubernetes.
- **Humans and non-human identities** — users, service accounts, and workloads.

It builds on open standards — **Cedar**, **Amazon Verified Permissions (AVP)**, **OPA**, **AuthZEN**, and **Shared Signals / CAEP** — so policies stay portable across your stack.
