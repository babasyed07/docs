Every agent action is authorized by the [Reva Trust Guardian](/ai-workload-security-overview#how-enforcement-works). How your agents *reach* the Trust Guardian depends on how they're built and where you can enforce. Pick the approach that matches your stack — you can mix approaches across a fleet. Grab the OAuth token and Policy Store ID from the store's [Settings → Connect to Reva Trust Guardian](/ai-workload-developer-settings#connect-your-agents-at-runtime).

## Choose Your Integration

| Approach | Best when | Status |
|:---------|:----------|:-------|
| **Python SDK** | You control the agent's code (LangChain, LangGraph, CrewAI, custom services). | Available |
| **Evaluation API** | You can add an HTTP/REST step but not embed the SDK (low-code platforms, gateways, other languages). | Available |
| **Java SDK** | JVM services that want the same decorator + proxy model. | Coming soon |
| **Kong plugin** | Enforce at the Kong API gateway, with no app changes. | Coming soon |
| **Istio plugin** | Enforce in the Istio service mesh, with no app changes. | Coming soon |

## Python SDK

When you control the agent's code, the `reva-ai-authz` SDK is the most complete option. A one-line decorator authorizes inbound calls, and an outbound proxy authorizes and token-forwards each call your agent makes — across agents, tools, MCP servers, and APIs.

## Evaluation API

When you can't embed the SDK, call the Trust Guardian's **Evaluation API** wherever you can add an HTTP/REST step — send the subject, action, resource, and context, and act on the allow/deny decision it returns.

<Card title="Agent Authorization Evaluation API" icon="plug" href="/ai-workload-developer-evaluation-api">
  Call the Trust Guardian directly from your enforcement point.
</Card>

## Gateway & Mesh Plugins

To govern traffic at the infrastructure layer instead of in code, Reva is building **Kong** (API gateway) and **Istio** (service mesh) plugins, plus a **Java SDK** for JVM services — all coming soon.

<Card title="Native Plugins" icon="puzzle-piece" href="/ai-workload-native-plugins">
  Kong, Istio, and the Java SDK — coming soon.
</Card>

## Not Sure Which to Use?

<Tip>
  If you can edit the agent's code, use the **Python SDK**. If you can add an HTTP/REST step but not code, use the **Evaluation API**. To enforce without touching the app, a **gateway or mesh plugin** is the path — tell your Reva contact which you need.
</Tip>
