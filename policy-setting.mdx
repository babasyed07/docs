title: "Settings"
---

The **Settings** tab is used to manage policy store ownership, permissions, data source configuration, and certification settings in Reva.

From this page, administrators can update policy store information, assign owners and collaborators, and select the preferred data source used for policy evaluation, simulations, and analytics.

## Access Policy Store Settings

To open policy store settings:

1. Go to the required policy store.
2. Click the **Settings** tab from the top navigation.
3. Use the left-side menu to configure:
   - **Info & Ownership**
   - **Data**

## Info & Ownership

Use **Info & Ownership** to manage basic policy store information and user access.

This section includes the following fields:

| Field | Description |
| --- | --- |
| Portfolio Name | The name of the portfolio or policy store. This identifies the policy store within Reva. |
| Owners | Users with ownership access to the policy store. Owners can manage policy store configuration and access permissions. |
| Description | A short description of the policy store and its purpose. |
| Viewers | Users who can view the policy store, policies, schema, test data, and configuration settings. |
| Editors | Users who can edit policy store configuration, policies, schema, test data, and related settings. |

<Info>
Owners, viewers, and editors can be selected from the available user list. Click **Save** after making changes.
</Info>

## Data

Use **Data** to configure which dataset is available for policy evaluation, simulations, and analytics.

This section allows you to select the preferred data source for the policy store. You can connect datasets from external sources or use uploaded datasets within Reva.

| Field | Description |
| --- | --- |
| Preferred Data Source | The dataset used by Reva for policy evaluation, simulations, and analytics. |

The available data source options are:

| Data Source | Description |
| --- | --- |
| Simulation | Uses simulation data for testing and validating policies before using them in live workflows. |
| Live | Uses live data for policy evaluation, analytics, and operational policy workflows. |

<Info>
Use **Simulation** while drafting or testing policies. Use **Live** when the policy store needs to evaluate policies against live data.
</Info>
