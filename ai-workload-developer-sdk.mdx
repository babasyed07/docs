The `reva-ai` SDK adds Reva authorization to an agentic system with two primitives: a **decorator** on the inbound side of every agent or MCP tool, and a **proxy** on the outbound side of every call to another protected service. Both consult the Reva PDP before work happens.

Prefer no code? You can call the [PDP evaluation API](/ai-workload-developer-evaluation-api) directly instead.

## Install

```bash
# Core (FastAPI + httpx + Pydantic)
pip install reva-ai

# With OpenTelemetry tracing
pip install "reva-ai[otel]"

# Everything
pip install "reva-ai[all]"
```

The SDK does not install your agent framework (LangChain, LangGraph, CrewAI, AutoGen, MCP) — those remain your dependencies.

## Environment Variables

Every service running the SDK sets these. Missing config **fails closed**.

| Variable | Required | Purpose |
|:---------|:---------|:--------|
| `RTG_URL` | yes | Base URL of the Reva PDP / Trust Gateway, e.g. `https://api.your-tenant.reva.ai` |
| `POLICYSTORE_ID` | yes | The policy store this service evaluates against |
| `RTG_AUTH_TOKEN` | yes | Platform API key, sent as `X-API-Token` on every PDP call |
| `RTG_DISABLED` | no | `true` disables PDP entirely. Defaults to `false`. **Never set in production.** |

## Inbound Authorization

Decorate the inbound boundary of each agent or MCP tool with `@reva_ai_authorise`. It checks the incoming request with the PDP before your handler runs.

<CodeGroup>
```python FastAPI agent
from fastapi import FastAPI, Request
from reva_ai.sdk.ai import reva_ai_authorise

app = FastAPI()

@app.post("/v1/run")
@reva_ai_authorise(
    agent_name="shipment-supervisor-agent",  # the agent's PDP id
    auth_key="Authorization",                # header with the caller's bearer token
    prompt_key="query",                      # body field carrying the prompt
    action="invokeAgent",                    # default
)
async def run(body: dict, request: Request):
    # PDP allowed. Your handler runs.
    return {"reply": "..."}
```

```python FastMCP tool
from mcp.server.fastmcp import FastMCP
from reva_ai.sdk.ai import reva_ai_authorise

mcp = FastMCP("billing-tools")

@mcp.tool()
@reva_ai_authorise(
    agent_name="reva-rate-mcp",   # the MCP server's PDP id
    agent_type="MCP",
    action="invokeTool",
    prompt_key="origin_code",
)
def get_freight_quote(origin_code: str, destination_code: str) -> dict:
    ...
```
</CodeGroup>

<Note>
  Decorate the route, not the application, and place `@reva_ai_authorise` **below** `@app.post(...)`. MCP discovery (`tools/list`, `initialize`) is never gated — only invocations (`tools/call`).
</Note>

## Outbound Authorization

Replace raw `httpx`/`requests` calls between protected services with the proxy. It mints a short-lived transaction token from the Trust Gateway and forwards it.

<CodeGroup>
```python Agent → Agent
from reva_ai.sdk.ai.proxy import revaclient

resp = await revaclient.proxy.agent(
    endpoint_url="http://billing-agent.internal/v1/run",
    method="POST",
    body={"text": "Get freight quote..."},
    prompt_key="text",
    resource_id="billing-agent",     # the target's PDP id
)
```

```python Agent → MCP tool
result = await revaclient.proxy.mcp(
    tool=langchain_mcp_tool,
    arguments={"container_id": "MSCU7841293"},
    mcp_client="http://127.0.0.1:9101/mcp",
    resource_id="reva-carrier-mcp",  # MCP server's PDP id
    endpoint_protected=True,
)
```

```python Agent → API
async with revaclient.proxy.api(
    endpoint_url="https://internal-api.example.com/users",
    method="GET",
    headers={"Accept": "application/json"},
) as response:
    response.raise_for_status()
    return response.json()
```
</CodeGroup>

On **deny**, the proxy raises `RevaAuthorizationError` and no downstream call is made.

## Framework Adapters

Each adapter maps the two primitives onto a framework's native API.

<Tabs>
  <Tab title="LangChain">
    ```python
    from reva_ai.sdk.ai.adapters.langchain import protect_runnable, protect_tool

    protected_planner = protect_runnable(planner_chain, agent_name="planner-subagent")
    protected_lookup = protect_tool(lookup_customer, tool_name="lookup_customer")
    ```
  </Tab>
  <Tab title="LangGraph">
    ```python
    from reva_ai.sdk.ai.adapters.langgraph import protect_node

    @protect_node(agent_name="planner-node")
    async def planner(state, config):
        ...
    ```
  </Tab>
  <Tab title="CrewAI">
    ```python
    from crewai import Agent
    from reva_ai.sdk.ai import reva_ai_authorise

    @reva_ai_authorise(agent_name="research-agent")
    def make_research_agent() -> Agent:
        return Agent(role="Researcher", goal="Investigate", backstory="...")
    ```
  </Tab>
  <Tab title="AutoGen">
    ```python
    from reva_ai.sdk.ai.adapters.autogen import protect_agent

    protected = protect_agent(assistant, agent_name="assistant")
    ```
  </Tab>
</Tabs>

For non-FastAPI inbound paths (queue workers, the a2a-sdk), seed identity with `set_caller_identity(...)` and call `authorise_inner_call_async(...)`.

## Security Model

- **Fail-closed by default** — missing config or an unreachable PDP denies.
- **Short-lived transaction tokens** — the SDK validates `exp` locally before forwarding.
- **Your request body is never mutated** — the SDK only adds one key (`rtg/a2a`) to outbound calls.
