---
title: "Configuring Application Details"
---
The application configuration process is clear and guided. Follow the steps below to add a new application context.  
<img height="200" src="images/application-context.png" />
<Info> Navigate to Manage Policies in the left main menu and click on + New Application.</Info>  
## Enter the application details
1. **Enter the Application Name**  
   Example: PetStore. This name identifies the application.  
2. **Write a Description**  
   Briefly describe what the application does.
3. **Choose the Category of the Application**  
   Example: Retail or Health. Categories help group applications by domain.  
4. **Assign Application Owner(s)**  
   Select the people responsible for managing the application.
5. **Add Application Tags**  
   Example: critical or external. Tags make filtering and searching easier.
6. **Create or Cancel**
   Click **Create** to save the application context, or **Cancel** to discard. 

<Info>After creation, a confirmation screen appears. A Default environment is linked. The application context is created and shows up in Pending state under Manage Policies. You can either close and plan to onboard the schema later, or click Onboard Schema to continue.</Info>
