---
title: "Setup Checklist"
---
Use this checklist to confirm that setup is complete before running the first import. It summarizes the steps described on the previous pages, grouped by where each step is performed.

## In the customer Microsoft 365 tenant

1. Register a single-tenant app in Entra ID.
2. Copy the Application (client) ID and Directory (tenant) ID.
3. Add the Application permissions `Sites.Read.All`, `Files.Read.All` and `Group.Read.All`.
4. Grant admin consent. Confirm that every row displays a green tick.
5. Create a client secret, copy its Value, and record its expiry date.
6. If app sign-ins or SharePoint access are restricted by IP address, allow Reva's outbound addresses.
7. For the Governance fields, configure Microsoft Purview: enable label processing, create and publish sensitivity labels, wait up to 24 hours, and apply the labels to files ([Turn on sensitivity labels in Microsoft Purview (for the Governance fields)](/sharepoint/register-the-app-in-microsoft-entra-id#turn-on-sensitivity-labels-in-microsoft-purview-for-the-governance-fields)).

## In the Reva console

1. Open Integrations → + Integration → Document Assets → SharePoint Data Discovery.
2. Enter the name and description. Set Deployment to Internal.
3. Enter the tenant ID, client ID, client secret, and sites to scan.
4. Click Next, then Activate.
5. Open the SharePoint tile → Details, then click the connection.
6. Click Test, then Sync.
7. Confirm that the import status is Completed and that the fetched and ingested counts match in View details.
8. Open Access Explorer and check the Document Assets card.
