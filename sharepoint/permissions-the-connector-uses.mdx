## Microsoft Graph application permissions

| Permission | Required | Used for | Without it |
| --- | --- | --- | --- |
| `Sites.Read.All` | Yes | List sites and their libraries, the Test probe, and each site's drive owner. | Test and import fail with 403. |
| `Files.Read.All` | Yes | Walk folders and files, and read each file's permissions, sensitivity label, retention label, versions and custom columns. | The import fails with 403. |
| `Group.Read.All` | Yes | Site owners, and the sensitivity label on the site's Microsoft 365 group. | Site owners and site labels are missing, with a warning on the run. |

## Calls and the permission each one needs

| Call | Permission | Fills |
| --- | --- | --- |
| `GET /sites/root?$select=id` | Sites.Read.All | Test only |
| `GET /sites/getAllSites` | Sites.Read.All | Workspace |
| `GET /sites/{id}/drives` | Sites.Read.All | Repository |
| `GET /sites/{id}/drive?$select=id,owner` | Sites.Read.All | Workspace associatedGroup |
| `GET /drives/{id}/root?$select=id` and `GET /drives/{id}/root/delta` | Files.Read.All | Folder and File |
| `GET /drives/{d}/items/{i}/permissions` | Files.Read.All | readers, editors, owners and their group sets, sharingLinks, hasAnonymousLink, hasExternalAccess, isShared |
| `GET /drives/{d}/items/{i}?$select=id,sensitivityLabel` | Files.Read.All | sensitivityLabelId, sensitivityLabelName |
| `POST /drives/{d}/items/{i}/extractSensitivityLabels` | Files.Read.All | labelAssignmentMethod |
| `GET /drives/{d}/items/{i}/retentionLabel` | Files.Read.All | retentionLabel |
| `GET /drives/{d}/items/{i}/versions?$select=id` | Files.Read.All | versionCount |
| `GET /drives/{d}/items/{i}/listItem/fields` | Files.Read.All | customMetadata |
| `GET /groups/{id}?$select=id,assignedLabels` | Group.Read.All | Workspace sensitivityLabelName |
| `GET /groups/{id}/owners/microsoft.graph.user?$select=id` | Group.Read.All | Workspace owners |

Per-file calls are sent 20 at a time through `POST /$batch`. A throttled call inside a batch waits for its own `Retry-After` and is sent again.

## What is intentionally absent

| Not requested | Effect |
| --- | --- |
| Any ReadWrite or FullControl permission | The connector cannot change sites, files, sharing, or labels. |
| Delegated permissions | No user signs in. The connector runs as the app. |
| Reads of `/content` | File contents are never downloaded. |
| `InformationProtectionPolicy.Read.All` | Not needed. Label names come from each file's own sensitivityLabel property. |
| `User.Read.All`, `Directory.Read.All` | People are recorded by Entra ID object id. |
| `Sites.Selected` | Not supported yet. The connector lists sites with `getAllSites`, which needs `Sites.Read.All`. |
