---
title: "Credentials Summary"
---
This page lists every credential the connector relies on, including who issues it, who holds it, and how to rotate or revoke it. Use this summary when your security team reviews the connector's access.

| Credential | Issued by | Held by | Notes |
| --- | --- | --- | --- |
| Client secret | Microsoft Entra ID, on the app registration | Reva, as the masked Client secret field | Expires on the date selected in [Create the client secret](/sharepoint/register-the-app-in-microsoft-entra-id#create-the-client-secret). Create a new secret before that date and enter it on the connection. An expired secret causes Test and every import to fail with an Entra ID error. |
| Directory (tenant) ID and Application (client) ID | Microsoft Entra ID | Reva, on the connection | Not secret. These values identify the tenant and the app. |
| Graph access token | Microsoft Entra ID, at run time | The connector, in memory | Valid for about an hour and renewed automatically. Never stored. |

To revoke access, delete the client secret or the entire app registration in Entra ID. The next Test or import will then fail.
