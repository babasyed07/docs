---
title: "Credentials Summary"
---

| Credential | Issued by | Held by | Notes |
| --- | --- | --- | --- |
| Client secret | Microsoft Entra ID, on the app registration | Reva, as the masked Client secret field | Expires on the date chosen in section [4.4](/sharepoint/register-the-app-in-microsoft-entra-id#create-the-client-secret). Create a new secret before then and enter it on the connection. An expired secret fails Test and every import with an Entra ID error. |
| Directory (tenant) ID and Application (client) ID | Microsoft Entra ID | Reva, on the connection | Not secret. They identify the tenant and the app. |
| Graph access token | Microsoft Entra ID, at run time | The connector, in memory | Valid for about an hour and renewed automatically. Never stored. |

To revoke access, delete the client secret or the whole app registration in Entra ID. The next Test or import then fails.
