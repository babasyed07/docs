---
title: "Permissions Required for Setup"
---
| Who | Needs | For |
| --- | --- | --- |
| Customer Entra ID administrator | Application Administrator or Cloud Application Administrator | Create the app registration and client secret. |
| Customer Entra ID administrator | Global Administrator or Privileged Role Administrator | Grant admin consent for Microsoft Graph application permissions. |
| Customer Purview administrator | Global Administrator, Compliance Administrator or Information Protection Administrator | Create, publish, and apply sensitivity labels ([Turn on sensitivity labels in Microsoft Purview (for the Governance fields)](/sharepoint/register-the-app-in-microsoft-entra-id#turn-on-sensitivity-labels-in-microsoft-purview-for-the-governance-fields)). |
| Reva console user | Rights to create integrations in the tenant console | Create, activate, test, and sync the integration. |
