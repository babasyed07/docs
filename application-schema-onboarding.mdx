---
title: "Onboarding Schema"
---
Schema onboarding defines the entities, attributes, and actions for your application context. Reva makes this simple with four options.  
<Info> After creating the application context, you can close and onboard later, or click Onboard Schema to continue. </Info>  
## Choose how to onboard a schema
1. **Upload JSON**  
   Import a schema from a JSON file. Example: banking-schema.json.
2. **Import from Library**  
   Pick a ready-made schema from the Reva Library. Example: RetailStoreSchema.
3. **Create with AI**  
   Let Reva AI create a schema suggestion for you.
4. **Design Manually**  
   Add principals, resources, and actions yourself.   
## What happens next
1. **Define Attributes:** Add fields such as ID, name, or role.  
2. **Add Runtime Attributes:** Include context values such as IP address or location.  
3. **Set Action Hierarchy:** Organize actions into logical groups.  
4. **Review Suggestions:** Accept or change the AI-generated schema and policies.  

<Info> When you accept the schema, Reva links it to the application context and its environment. You can then upload test data or go straight to Policy Designer. </Info>
